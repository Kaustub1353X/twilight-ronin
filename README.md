# Twilight Ronin

A 2D endless runner where a ninja sprints through a neon sunset. Jump, double jump and slide past flames and bats. One hit ends the run, so timing is everything.

**Play it:** https://YOUR-GITHUB-USERNAME.github.io/twilight-ronin/

## Features

- Double jump and slide mechanics
- Power-ups: shield (blocks one hit) and coin magnet
- Coins, level progression and a best score saved with `localStorage`
- Parallax backgrounds with a new colour palette every level
- Sound effects and music generated entirely with the Web Audio API
- Keyboard and touch controls, plus pause, mute and fullscreen

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Jump (press again in the air to double jump) | Space, Up Arrow, W | Tap, or the Jump button |
| Slide | Down Arrow, S | Swipe down, or the Slide button |
| Pause | P or Esc | Pause button |
| Mute | M | Sound button |
| Fullscreen | F | Fullscreen button |

## Run it locally

No build step and no dependencies. Download `index.html` and open it in any modern browser.

## Built with

HTML, CSS and JavaScript (Canvas 2D, Web Audio API). Fonts: Bungee and Chakra Petch from Google Fonts.
